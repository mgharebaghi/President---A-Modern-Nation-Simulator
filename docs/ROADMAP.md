# Development roadmap

The owner approved phase 01 only on 2026-10-19, with Rust/WASM allowed where evidence justifies it. Each phase requires its own branch, small commits, PR, CI and manual test instructions. The owner's later 2026-10-19 instruction grants standing approval to merge completed phases after successful latest-head checks, superseding the original per-merge confirmation requirement. Approval for one phase never authorizes starting the next. Scope expansion and expensive architecture changes require discussion. Record human feedback truthfully; passing CI is not evidence that a human test occurred.

| Phase | Deliverable / exit condition |
| --- | --- |
| 01 — Foundation | Bilingual capital district, camera, selection, correct calendar, shared day/night clock, worker boundary and passing checks. Owner can inspect the scene before merge. |
| 02 — First playable loop | Real treasury inflows/outflows, one funded power project with time and visual completion, capacity effects, save/resume; all effects traceable. |
| 03 — Countries and geography | Interactive world/national map, three materially different playable countries, president identity and difficulty; differences affect phase 02. |
| 04 — Production and trade | Production sectors, energy, jobs, consumption, resource constraints and imports/exports with explained policy consequences. |
| 05 — Macroeconomics | Consistent budgets, inflation, growth, debt, interest, exchange rates, reserves, investment and historical accounts. |
| 06 — Society | Cohorts, demographics, migration, income distribution, health and education; group-specific responses and realistic delays. |
| 07 — Cabinet | Appointments, skills, ideology, corruption, disagreement, memory and resignation affect implementation; presidential orders cannot be secretly overridden. |
| 08 — Diplomacy | Independent governments, multidimensional ties, messages, negotiation, treaties and diplomatic memory with explainable decisions. |
| 09 — Elections | Parties, promises, polling, turnout and cohort voting produce explainable wins/losses. |
| 10 — Political crisis | Visible protests/strikes, political responses, authoritarian change and legitimacy costs tied to existing systems. |
| 11 — Strategic security | Readiness, logistics, alliances, conflict/peace, casualties, displacement, economic and infrastructure effects. |
| 12 — Release readiness | Global crises, tutorial, sandbox, autosave/multiple slots, expanded living city, sound, quality/performance and full-term balance. |

Phases depend on earlier delivered foundations. If a later phase is too large, propose smaller independently testable deliveries before starting it. Translation, truthful news/explanations, tests, asset licensing, documentation and visual QA accompany each subsystem.

Human feedback begins at the first working interaction inside each phase. Reports must distinguish implementation, automated verification, owner's manual review, merge and publication. No placeholder controls, fabricated economic metrics, made-up preview URLs or unmeasured benchmark claims.
