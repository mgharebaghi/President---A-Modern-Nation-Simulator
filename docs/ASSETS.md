# Asset provenance

All city geometry is generated by repository code in `src/render/city.ts`: buildings, windows, trees, street furniture, roads, bridge and river. There are no downloaded models, textures, photos or AI-generated assets in phase 01. Facades use shared materials and instanced geometry.

- UI icons and favicon: original SVG paths in this repository, no third-party icon pack.
- Vazirmatn: bundled locally by `@fontsource/vazirmatn`, SIL Open Font License 1.1. Upstream: https://github.com/rastikerdar/vazirmatn . Package license retained in node_modules; redistribution text accompanies the production build in `public/THIRD_PARTY_NOTICES.txt`.
- Manrope: bundled locally by `@fontsource/manrope`, SIL Open Font License 1.1. Upstream: https://github.com/sharanda/manrope . Same distribution policy.
- Three.js: MIT, https://github.com/mrdoob/three.js . Other runtime library notices are recorded alongside the production build.

The repository currently has no owner-selected project-wide license. Public visibility alone does not establish a license grant for original code. Do not choose one on the owner's behalf. Third-party licenses remain applicable to their own components.
